## Local Review

From the repository root:

```sh
npm ci
npm ci --prefix packs/easy-as-pie/demo
npm run verify
node scripts/serve-assets.mjs 18553
```

Open <http://127.0.0.1:18553/packs/easy-as-pie/demo/>. Select Sixteenths, return to 1/2 And 2/4, open the drawer, and try Cut Pie A followed by Regroup Pie A. Compare Focus One Piece, Correct and Not Yet. Buttons are keyboard accessible and animated source methods respect reduced motion. Controls are a small demonstration adapter around the original renderer; assessment text comes from this demo.

This is an unbundled local live source asset demo, not a new game build or standalone GLB export. Its footer records the exact source and upstream build. The demo's own pinned engine avoids upgrading the older packs. No network/CDN assets are requested in the browser.
