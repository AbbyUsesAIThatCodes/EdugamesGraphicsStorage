## Local Review

From the storage root, install dependencies with `npm ci`, run `npm run verify`, then `node scripts/serve-assets.mjs 18552`. Open <http://127.0.0.1:18552/packs/three-kinds-of-levers/demo/>. This serves only a local live source asset demo. There is no new game build, portable GLB claim, or hosted preview.

Select the classroom, four desks, push bar, extinguisher and lever views. Select Load to inspect the interaction glow, then compare the six diagrams with role names shown and hidden. The adapter uses original generators; room/component cameras and gallery layout belong to this demo. Approximate room dimensions are metres; the original apparatus scene scales the room by 40 to match its 25-mm units. This is not a surveyed or certified model.

Private classroom photos were reference-only and are excluded. Every visible texture is generated by the archived code. No student markings, source images, credentials, game deployment configuration or private course packets are included. Generic signs in the room are procedural.

The source's optional geometry batching reports incompatible index attributes for some buckets, then keeps their original meshes. The demo preserves that fallback and records the exact diagnostics; room, desk, door and extinguisher rendering were inspected. No unexpected browser errors or external requests occurred. The toon room helper removes roughness/metalness arguments; its steel-colored surfaces are not physically metallic materials.

Selection glow is green; answer feedback uses separate text and red/green borders. Source quiz CSS later overrides its border with amber. These implemented treatments are documented rather than standardized across games. Source archive is a graphics closure, not the full playable lesson.
